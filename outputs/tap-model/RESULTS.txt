Tap Predictor: LightGBM для пространственного распознавания касаний

Открой TapPredictor.app рядом с папкой tap-model.
Пробел включает/приостанавливает распознавание, Esc ставит на паузу.
Коротко коснись любой точки один раз и убери палец.
Примерно через полсекунды зелёная клетка покажет предсказанную зону,
а белое перекрестие — предсказанные координаты внутри сетки.
Дождись «можно тапнуть снова» перед следующим касанием.
Command+Q — выйти. Угол крышки не блокируется.
Это демонстрация распознавания, системные клики мышью не выполняются.

Модель — два LightGBM-регрессора для координат x и y в единицах клеток.
Потери — сумма квадратов ошибок координат. Близкие промахи штрафуются
меньше, дальние — больше. Категориального обучения на 260 классах нет.
258 признаков описывают форму и направления импульсов гироскопа,
акселерометра и текущий угол крышки. Признаки не включают правильный
номер клетки или её координаты; они используются только как цель обучения.

Хронологическое разделение (индексы исходного сеанса):
<340 — обучение; 340..459 — подбор параметров; >=460 — финальный тест.
После выбора параметров модель для теста обучалась на примерах <460.
Тест не использовался для выбора параметров. После измерения качества
модель приложения переобучена с выбранными параметрами на всех допустимых
примерах. Поэтому тестовые метрики относятся к модели до этого последнего
переобучения, а точность финальной модели на новых тапах ещё не измерена.

На 102 отложенных автоматических записях:
Точная клетка: 3 из 102 (2,94%).
В пределах одной клетки по каждой оси: 16 из 102 (15,69%).
В пределах двух клеток: 37 из 102 (36,27%).
В пределах трёх клеток: 63 из 102 (61,76%).
Среднее евклидово расстояние до заданного центра: 4,44 клетки.
Для постоянного предсказания среднего центра: 6,20 клетки.

Все 116 отложенных примеров, включая ручные подтверждения:
Точная клетка: 3 из 116 (2,59%). Средний промах: 4,62 клетки.

Это пока низкая точность для уверенных кликов. Данные сняты за один сеанс,
с небольшим количеством повторов каждой клетки и меняющимся углом крышки.
Ручные подтверждения имеют неизвестное точное время касания; для них
выбирался кандидат импульса, и их вес при обучении уменьшен до 0,3.
Некоторые ручные интервалы без подходящего импульса исключены.
Подробности и все параметры: metrics.json.
Предсказания на отложенных примерах: heldout-predictions.json.
Правильная точка в датасете — предписанный центр цели; реальное положение
пальца независимо не измерялось. Для проверки обобщения нужен новый сеанс.

Приложение выполняет экспортированные деревья нативно на Swift.
Ему не нужны Python, LightGBM или сеть во время работы.
Совпадение Swift-признаков и предсказаний с Python проверено на 5 реальных
примерах: максимальная численная ошибка меньше 1e-7.

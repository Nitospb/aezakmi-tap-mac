Добавление микрофона с учётом фонового звука

Источник: уже записанный встроенный микрофон, 44100 Гц, Float32; новая запись не включалась.
Аудио привязано к часам датчиков по audio-chunks.jsonl, паузы не считаются непрерывным звуком.
Тап ищется только в коротком окне возле импульса IMU, а не по всей дорожке.
Шумовой спектр оценивается до тапа (−340..−100 мс). Извлекается 202 признака спектра, атаки, затухания, относительного превышения фона и формы импульса.
Абсолютные признаки речи/музыки и распознавание речи не используются.
Стандартная нормализация обучается только на обучающей части.

Проверенные варианты: линейный классификатор, SVM, ExtraTrees, LightGBM; SVM с добавлением реальных фоновых отрезков в обучение.
Фон для смешивания берётся только из обучающего прохода, не из валидации или теста.
Также сравнивались фиксированный вес звука и вес, уменьшающийся при низком отношении сигнал/шум.
Выбран на втором проходе линейный классификатор аудио с фиксированным весом 10%; остальные 90% — прежняя модель движения/угла/света.
Усиление шума и автоматическое уменьшение веса проверены, но выбранный вариант на валидации оказался лучше без них.

Повторная проверка на тех же 217 автоматических тапах третьего прохода:
Без микрофона: точная клетка 10.60% (23/217), рядом ≤1 клетка по каждой оси 58.06%, средний промах 2.02 клетки.
С микрофоном: точная клетка 12.44% (27/217), рядом ≤1 клетка по каждой оси 58.99%, средний промах 2.02 клетки.
Только звук (отдельная выбранная аудиомодель): точная клетка 3.69% (8/217), рядом ≤1 клетка по каждой оси 17.51%, средний промах 4.87 клетки.

Изменено предсказаний: 35; исправлено точных ошибок: 7; потеряно точных попаданий: 3.
Точная парная проверка улучшения: p=0.344.
1000 перемешиваний звука: средняя точность 10.92%, не хуже настоящего звука — 5.5% перемешиваний.
Это небольшой результат; статистически убедительного выигрыша пока не получено. Нужен отдельный новый сеанс для подтверждения.

Медиана отношения сигнал/фон: 2.71 дБ; медианное смещение найденного аудиоимпульса относительно IMU: 23.4 мс.
Аудиопокрытие: 217/217 тестовых тапов. Сложные случаи не удалялись из итогового теста.

model.joblib — отдельный финальный вариант с микрофоном, обученный после оценки на всех пригодных данных.
evaluation-model.joblib — вариант первых двух проходов, к которому относятся проценты выше.
Приложение не менялось: пока использует прежнюю модель без микрофона.
Третий проход уже использовался ранее; это повторное сравнение, не независимая проверка.
Источники и воспроизведение: audio_features.py, train_audio.py, verify_report.py.
